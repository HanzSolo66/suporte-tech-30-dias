# Semana 1: Fundamentos de Programação

Esta semana é dedicada a entender como o computador pensa. Não há código para escrever ainda — apenas conceitos fundamentais que serão a base de tudo.

## Objetivo da Semana
Ao final desta semana, o aluno deve ser capaz de descrever o que é programação, lógica, variáveis, operadores, condições e loops, e entender como esses conceitos se aplicam no dia a dia do suporte técnico.

## Conexão com o Suporte Técnico
Entender lógica e variáveis permite ao analista de suporte compreender logs de sistema, scripts de automação e fluxos de atendimento. Quando um sistema retorna um erro, ele está executando uma lógica condicional — e você precisa entendê-la para diagnosticar o problema.
